# Daily Task Manager

A simple Android app for planning and tracking your daily tasks, built with Flutter.

## Download

Download [`DailyTaskManager.apk`](DailyTaskManager.apk) (~48 MB) and open it on your Android phone.

## Install

1. Download the APK onto your Android device.
2. Open it from your Downloads folder or notifications.
3. If Android blocks it, allow **Install unknown apps** for your browser or file manager when prompted.
4. Tap **Install**, then open **Daily Task Manager**.

## Features

- **Add tasks** with a title, an optional description and a date.
- **Edit** a task at any time.
- **Mark tasks complete** with a checkbox, or uncheck them again.
- **Delete** a task, with a confirmation prompt so you don't lose it by accident.
- **Filter** the list by **All**, **Pending** or **Completed**.
- **Saved on your device**: tasks stay after you close the app. No account or internet connection is needed.

## Built with

- Flutter (Dart)
- `shared_preferences` to store tasks on the device
